# 태블릿 페이지 보기 제스처 회귀 계획

## 환경

- Windows 11, 로컬 Docker Compose `service`, Playwright Chromium 터치 컨텍스트
- PDF.js 레거시 뷰어와 WebGPU 뷰어를 각각 실행
- 5페이지 PDF, 태블릿 화면 768×1024 및 1024×1366

## 절차

1. 연속 스크롤을 끈 한 페이지 보기에서 위·아래 쓸기로 다음·이전 페이지를 이동한다.
2. 연속 스크롤을 끈 두 페이지 보기에서 왼쪽·오른쪽 쓸기로 다음·이전 묶음으로 이동한다.
3. 화면 맞춤에서는 `touch-action: none`을 적용하여 Safari의 기본 스크롤이 제스처를 취소하지 않도록 한다.
4. 300%로 확대한 뒤 가로 스크롤 중간에서 쓸면 페이지가 넘어가지 않고 문서 내부 이동이 우선인지 확인한다.
5. 연속 스크롤을 켜면 `touch-action: auto`로 돌아가는지 확인한다.
6. 빌드, Docker 갱신, 브라우저 테스트, diff 검사를 실행한다.

## 실패 기준

- 좌우 쓸기가 페이지를 변경하지 못함
- 확대된 페이지를 중간에서 쓸었는데 문서가 넘어감
- 연속 스크롤에서도 기본 터치 스크롤이 막힘
