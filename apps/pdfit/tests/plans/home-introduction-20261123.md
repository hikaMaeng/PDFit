# 홈 소개 및 탐색 테스트

## 목표와 환경

2026-11-23 작성. Windows의 Free Docker 서비스와 헤드리스 Chromium에서
홈 안내의 기능 설명, 링크, 좁은 화면과 RTL 레이아웃을 검증한다.

## 실행 및 합격 기준

1. `npm run deploy:standalone`을 실행하고 `/health` HTTP 200 및
   컨테이너 내부의 라이브러리 경로를 확인한다. 폴더 API는 폴더 하나 이상을 반환해야 한다.
2. `PDFIT_TEST_ORIGIN`과 `PDFIT_EVIDENCE_DIR`을 지정하고
   `node apps/pdfit/tests/home-introduction-browser.mjs`를 실행한다.
3. 한국어 1440px 다크, 375px 라이트, 아랍어 1280px 다크, 영어 1024px 라이트에서
   제목과 방향을 확인한다. 본문은 가로로 넘치지 않아야 하고 한국어에서는
   데스크톱의 두 기능 패널이 나란히, 모바일에서는 위아래로 배치돼야 한다.
   아랍어에서 사이드바는 본문 오른쪽에 놓이고 AI 설정 링크를 누를 수 있어야 한다.
4. 각 링크를 클릭해 동적으로 결정한 기본 폴더, 태그 인덱스, 미분류,
   즐겨찾기, 클립 및 설정 화면에 도착하는지 확인한다. 표시 이름 번역 API는
   브라우저에서 원래 이름을 돌려주도록 해 외부 모델을 호출하지 않는다.

## 로케이터와 증거

홈은 `main` 안에서 `h1`, 섹션의 접근 가능한 제목과 링크 이름을 사용한다.
도착 화면은 제목 및 기존 `favorites-title`, `untagged-title`을 사용한다.
헬스·라이브러리 집계, 브라우저 버전, 탐색 주소, 페이지 오류, 스크린샷을 기록한다.
