# 문서 목록 파일명 굵기 검증

## 목적

목록형 문서 보기의 파일명만 얇은 글씨(300)로 표시하고, 라이트/다크 모드에서 동일하게 적용되는지 확인한다. 폴더명 및 기타 메뉴 글씨는 범위에 포함하지 않는다.

## 환경

- Windows 11, Docker Compose `service`, Chromium/Playwright
- 로컬 서비스 `http://127.0.0.1:15201`
- 기존 문서 데이터 읽기만 사용하며 이름 변경/삭제는 수행하지 않음

## 절차

1. `@pdfit/pdfit`, `service` 빌드 후 루트 Compose에서 서비스를 재생성한다.
2. 로컬 미리보기 계정으로 접속하여 기본 폴더의 목록형 문서 보기를 연다.
3. 라이트와 다크 모드에서 첫 파일명의 계산된 `font-weight`와 `font-synthesis`를 확인한다.
4. 각 모드의 스크린샷을 저장하고 레이아웃 깨짐 여부를 확인한다.
5. `git diff --check`와 Compose 상태를 확인한다.

## 통과 기준

- 양쪽 모드 모두 파일명 `font-weight: 300`, `font-synthesis: none`
- 파일명이 표시되고 줄/열 배치가 유지됨
- 빌드 및 Docker 서비스 정상, 브라우저 오류 없음
