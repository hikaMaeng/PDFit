# 로컬 폴더 생성 LNB 동기화 테스트 계획

## 목적

로컬 PDFit에서 폴더 생성 완료 전에 폴더 화면으로 이동하지 않으며, 생성 직후 왼쪽 LNB에 새 폴더가 표시되는지 검증한다.

## 환경

- Windows 11
- Docker Compose의 `pdfit` 서비스
- Chromium (Playwright, headless)
- 기본 URL: `http://127.0.0.1:15201`

## 사전 조건

- `pdfit` 컨테이너가 healthy 상태여야 한다.
- 테스트 폴더 이름은 실행 시각을 포함해 기존 서재와 충돌하지 않아야 한다.

## 절차

1. 루트 화면을 열고 네트워크 유휴 상태를 기다린다.
2. 폴더 생성 버튼을 눌러 고유한 폴더명을 입력한다.
3. `POST /api/folders` 요청 전달을 일시 지연한다.
4. 응답 전에는 생성 다이얼로그가 `Creating...` 상태이며 폴더 URL로 이동하지 않았는지 확인한다.
5. 요청을 전달하고 성공 응답을 받은 뒤 폴더 URL로 이동하는지 확인한다.
6. LNB에서 새 폴더명이 표시되는지 확인한다.
7. `GET /api/folders` 결과에도 새 폴더가 포함되는지 확인한다.
8. 스크린샷을 저장하고 테스트 폴더를 삭제한다.

## 합격 기준

- 서버 생성 성공 전에 화면 이동이 발생하지 않는다.
- 생성 성공 직후 LNB와 API 목록 모두 새 폴더를 포함한다.
- 테스트 종료 후 생성한 폴더가 삭제된다.
