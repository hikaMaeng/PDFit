# 북마크 모달 삭제 수용 계획

## 범위

- 북마크 상세 모달 하단 좌측에 휴지통 아이콘을 제공한다.
- 북마크 본문 카드 우상단에도 휴지통 아이콘을 제공한다.
- 삭제 요청 성공 시 모달을 닫고 북마크 모델과 갤러리를 즉시 갱신한다.
- 서버는 북마크 메타데이터와 해당 캡처 JPEG 파일을 함께 정리한다.

## 검증

`test/20260811/bookmark-delete-modal.mjs`가 임시 북마크를 생성한 뒤 모달 삭제를 실행하고, 모달 닫힘·카드 제거·API 목록 제거·캡처 자산 404를 확인한다.

`test/20260811/bookmark-card-delete.mjs`는 카드 우상단 휴지통을 클릭해 모달이 열리지 않고 동일하게 카드·API·캡처 자산이 삭제되는지 확인한다.
