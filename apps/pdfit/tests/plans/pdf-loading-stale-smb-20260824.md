# PDF 로딩 및 오래된 SMB 연결 복구 테스트 계획

## 목표

오래된 뷰어 창 정보가 남아 있어도 PDF 선택 시 `about:blank`에 머물지 않고, CIFS 서재의 실제 PDF 페이지가 로드되는지 확인한다.

## 절차

1. 15201의 health 응답을 확인한다.
2. CIFS 볼륨에서 34MB PDF 전체를 읽어 마운트 경로를 검증한다.
3. 브라우저 저장소에 오래된 뷰어 창 정보를 만든다.
4. 라이브러리에서 PDF를 선택한다.
5. 새 창 URL, 페이지 수, 로딩 후 health 상태를 확인한다.

## 통과 기준

- 새 창 URL이 `/viewer/`를 포함하고 `about:blank`가 아니다.
- 뷰어 상태의 페이지 수가 1 이상이다.
- PDF 로딩 후 15201 health가 HTTP 200이다.
