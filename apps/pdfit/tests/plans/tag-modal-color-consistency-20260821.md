# 태그 관리 모달 색상 일치 검증 계획

## 목적

폴더 및 태그 상세 화면의 태그 관리 모달에서 각 태그 칩이 저장된 태그 색상으로 표시되는지 검증한다.

## 환경

- Windows 11
- Docker Compose 로컬 런타임
- PDFit v0.4.4
- Chromium 기반 인앱 브라우저

## 절차

1. 전체 워크스페이스 빌드를 실행한다.
2. 로컬 PDFit 컨테이너를 재빌드하고 라이브러리 인덱스를 갱신한다.
3. `/folder/이북`에서 서로 다른 색상의 태그가 달린 PDF의 태그 관리 모달을 연다.
4. 모달 태그 칩의 글자, 테두리, 삭제 아이콘 색상을 확인한다.
5. 컨테이너 배포 상태 검증을 실행한다.

## 기대 결과

- 새 로컬 태그의 기본 색상은 `#22c55e`이다.
- 기존 태그는 저장된 고유 색상을 유지한다.
- 태그 관리 모달의 칩 글자, 테두리, 삭제 아이콘 색상이 해당 태그 색상과 일치한다.
- 빌드 및 로컬 컨테이너 검증이 성공한다.
