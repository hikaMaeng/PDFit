# 뷰어 오버레이 휠 페이지 이동

## 목적

1페이지 및 2페이지 보기에서 주석 도구 팔레트나 저장된 영역 북마크가 마우스 아래에 있어도 휠 페이지 이동이 유지되는지 검증한다.

## 절차

1. PDFit을 빌드하고 루트 Docker Compose로 재배포한다.
2. 기본 렌더러와 PDF.js 대체 렌더러에서 영역 북마크 도구를 활성화한다.
3. 도구 팔레트 위에서 휠을 내려 1페이지 보기 `1→2`, 2페이지 보기 `1→3` 이동을 확인한다.
4. 기본 렌더러에서 실제 저장된 영역 북마크 위에 마우스를 두고 휠을 내려 다음 페이지 이동을 확인한다.
5. Docker 상태와 오류 로그를 확인한다.

## 기대 결과

- 오버레이가 휠 입력을 가로막지 않는다.
- 1페이지 보기는 한 페이지, 2페이지 보기는 두 페이지 단위로 이동한다.
- 연속 스크롤 동작은 기존 방식을 유지한다.
