## 단계

1. 단위 테스트 `npm run test:ai-tags`(`ai-tagging`, `tag-ai-server`, `auto-tags-multi`).
2. 실제 실행: `POST /api/tags/book/이북/AI 엔지니어링.pdf/auto`. 응답 `suggestedTags` 수가 4~6이고 첫 태그가 분류 체계 값.
3. LM Studio 로그(`~/.lmstudio/server-logs/2026-11/`)에서 그 요청의 시스템 프롬프트, `reasoning_effort`, 목차·소개 길이, 장르 경로, `availableTags` 수, 응답과 토큰 수 확인.
4. 브라우저 `apps/pdfit/tests/auto-tags-browser.mjs`: 1440px 목록·표지 보기, 375px 표지 보기에서 보이는 칩 = `GET /api/tags/인공지능/books`의 그 책 `tags`, 페이지 태그 `인공지능` 포함, 375px 가로 넘침 0, `pageErrors` 없음, 쓰기 요청 없음.
