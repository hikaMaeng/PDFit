# 개인 문서 정보와 도서 모드 저장 검증

## 목적

일반 PDF의 불필요한 작성자·작성 기관·작성일을 숨긴다. `문서 정보 찾기`가 공개 도서 데이터와 일치한 경우에만 저자·ISBN 등 도서 전용 항목을 표시하고, 저장 후 다시 열 때도 도서 화면으로 복원한다.

## 환경 및 데이터

- Windows 11, Docker Compose `service`, Chromium/Playwright
- 로컬 미리보기 `http://127.0.0.1:15201`
- 메타데이터 GET/PUT은 브라우저에서 가로채 모의 응답하며 실제 저장 데이터 변경 없음

## 절차

1. `@pdfit/pdfit`, `@pdfit/service_domain`, `service`를 빌드하고 Compose 서비스를 갱신한다.
2. 일반 문서 정보 창에 제목·부제·키워드만 보이는지 확인한다.
3. 검색 실패 응답에서는 도서 전용 항목이 열리지 않는지 확인한다.
4. 검색 성공 응답에서 도서 전용 항목이 표시되는지 확인하고 모의 저장 요청에 `documentType: book`이 담기는지 확인한다.
5. 페이지를 새로고침해 다시 열고 저자·도서 필드가 유지되는지 확인한다.
6. 이전 형식의 ISBN 데이터, 명시적 `document` 값을 서버 정규화 테스트로 확인한다.
7. 스크린샷, 브라우저 오류, `git diff --check`, Docker 건강 상태를 점검한다.

## 통과 기준

- 일반 문서의 작성자·작성 기관·작성일·언어 입력칸 없음
- 일반 문서에 수동 도서 모드 버튼이 없고 검색 실패에서는 도서 항목이 표시되지 않음
- 검색 성공과 저장 후 새로고침에서는 도서 화면으로 복원
- 실제 메타데이터 PUT 없음, 서버 정규화 및 빌드 통과, 서비스 healthy
