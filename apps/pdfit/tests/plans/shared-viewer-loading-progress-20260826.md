# 공통 PDF 로딩 진행 막대 테스트 계획

## 목적

GPU 뷰어와 기본 PDF.js 뷰어가 운영체제와 관계없이 동일한 로딩 진행 막대를 표시하는지 확인한다.

## 절차

1. 기본 뷰어를 강제로 선택한다.
2. PDF 다운로드 속도를 제한해 로딩 UI를 관찰할 시간을 확보한다.
3. Windows, macOS, Linux aarch64(ASUS GX10) 사용자 에이전트에서 공통 진행 막대가 표시되는지 확인한다.
4. PDF.js 다운로드 바이트에 따라 퍼센트가 증가하고 완료 후 사라지는지 확인한다.
5. 로컬·서비스 빌드 및 Docker 상태를 확인한다.

## 합격 기준

세 환경에서 동일한 가로 막대가 표시되고, 기본 뷰어의 퍼센트가 증가하며, 브라우저 오류가 없어야 한다.
