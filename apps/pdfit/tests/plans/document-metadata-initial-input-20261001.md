# 문서 정보 첫 입력 지연 개선 검증 계획

## 목적

문서 정보 버튼 클릭 후 창 표시, 제목 입력 가능, 서버 정보 조회 완료 시간을 분리 측정한다. 느린 조회 중 사용자가 입력한 값을 서버 응답이 덮어쓰지 않는지 확인한다.

## 환경

- Windows 11, 로컬 `docker compose`의 `service`, `http://127.0.0.1:15201`
- Playwright Chromium, 1280×800
- 기존 라이브러리의 `스프링 5 마스터 2e.pdf`

## 절차

1. 로컬 미리보기 로그인 후 해당 PDF가 있는 폴더를 연다.
2. 문서 정보 버튼을 눌러 창 표시와 제목 필드 입력 가능 시간을 측정한다.
3. 메타데이터 GET 응답 및 조회 완료 시간을 기록한다.
4. 창을 닫고 같은 문서를 다시 열어 중복 요청이 없는지 확인한다.
5. 새 페이지에서 메타데이터 응답을 1.2초 지연시키고, 조회 중 제목을 입력한다.
6. 조회 완료 뒤 제목과 저장 버튼 상태를 확인한다. 실제 저장은 수행하지 않는다.

## 통과 기준

- 첫 입력은 500ms 이내 가능하며, 1.2초 지연 응답에도 작성한 제목이 유지된다.
- 메타데이터 GET은 200이고 같은 문서 재열기에는 추가 GET이 없다.
- 패키지/서비스 빌드, Docker 서비스 갱신 및 건강 상태 확인에 성공한다.
