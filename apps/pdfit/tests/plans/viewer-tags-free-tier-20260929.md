# 뷰어 태그·무료 권한 검증 계획

## 목적

뷰어 헤더 태그, 신규 태그 색상, 태그 표시 형식, 태그 관리 파일명 안내, 무료 권한의 PDF 자동 분류 숨김을 검증한다.

## 절차

1. 무료 체험 권한으로 폴더를 열고 목록의 일괄 및 개별 PDF 자동 분류 버튼이 없는지, 태그 관리창의 자동 분류 버튼은 표시되지만 비활성 상태인지 확인한다.
2. 태그 관리창에서 `파일명 : 실제파일명.pdf` 안내를 확인한다.
3. 새 태그 색상을 선택한 뒤 태그를 생성하고 색상 저장 요청을 확인한다.
4. 목록과 관리창의 태그가 공통 태그 칩 형식을 사용하는지 확인한다.
5. 같은 PDF를 뷰어로 열어 파일명 오른쪽에 기존 태그와 신규 태그가 표시되는지 확인한다.

## 통과 기준

- 무료 권한에는 목록의 PDF 자동 분류 진입점이 렌더링되지 않으며, 태그 관리창의 버튼은 비활성 상태로 표시된다.
- 선택한 신규 태그 색상이 저장되고 즉시 표시된다.
- 파일명 안내와 뷰어 헤더 태그 위치가 요구사항과 일치한다.
- 목록, 관리창, 뷰어가 같은 공통 태그 칩을 사용한다.
