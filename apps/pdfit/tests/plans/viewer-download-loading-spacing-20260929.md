# 뷰어 다운로드·로딩·여백 검증 계획

## 목적

다운로드 명칭과 Windows 저장 위치 선택 계약, 확대율 가운데 정렬, 문서 로딩 게이지 및 초기 표시 시간, 좌우 여백 축소를 검증한다.

## 절차

1. 다운로드 대화상자의 제목과 실행 버튼이 `다운로드`인지 확인한다.
2. File System Access API를 모의해 추천 파일명, PDF 바이트 쓰기, 파일 닫기 호출을 확인한다.
3. API가 없을 때 기존 브라우저 다운로드가 유지되는지 확인한다.
4. 300ms 지연된 PDF 응답에서 로딩 게이지가 표시되는지 확인한다.
5. 저장된 3페이지가 최초 우선 표시되고 전체 초기 표시 시간이 3초 미만인지 확인한다.
6. 확대율 입력의 텍스트 정렬과 가로 맞춤 치수를 확인한다.
7. 가로 맞춤 좌우 여백이 각각 24px에서 12px로 줄었는지 확인한다.

## 통과 기준

- 다운로드 및 저장 선택 계약이 모두 통과한다.
- 로딩 게이지가 실제 PDF 대기 중 표시된다.
- 300ms 인위 지연을 포함한 첫 페이지 표시가 3초 미만이다.
- 좌우 여백 합계가 24px이고 확대율 값이 가운데 정렬된다.
