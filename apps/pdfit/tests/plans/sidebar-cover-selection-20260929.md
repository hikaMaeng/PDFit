# 왼쪽 목록과 표지 체크박스 검증

## 환경

Windows 11, 루트 Docker Compose service, http://127.0.0.1:15201, Playwright Chromium.
인증·Drive API는 브라우저 테스트 데이터로 대체한다. 사용자 실제 문서는 변경하지 않는다.

## 실행

1. `npm run build --workspace=@pdfit/pdfit`
2. `npm run build --workspace=service`
3. `docker compose up -d --build service`
4. `node apps/pdfit/tests/viewer-tags-free-tier-browser.mjs`

## 확인 사항

- 왼쪽 폴더·태그 항목은 이름과 개수를 유지하고 항목 아이콘만 제거한다.
- 폴더·태그 섹션 제목 아이콘과 선택·이동 경로는 유지한다.
- 태그별 문서 목록 체크박스는 호버 전부터 보이며 개별/전체 선택·해제가 동작한다.
- 표지 체크박스는 카드 하단 우측 작업 영역에 위치하며 클릭으로 선택·해제된다.
- 1440px 및 390px 화면에서 체크박스가 카드 내부에 있고 잘리지 않는다.
- 기존 목록 열, 태그 클릭 이동, 신규 태그 색상, 무료 분류 제한, 중복 안내 수정은 회귀 테스트를 통과한다.
- 상단 설정 버튼으로 언어·테마 모달을 열고 라이트/다크 및 영어/한국어 전환이 즉시 적용되는지 확인한다.
- 새로고침 후 언어·테마 선택값이 유지되는지 확인한다.
- 폴더·태그 관리창의 색상 선택 버튼이 클릭 전에 색상 원을 표시하는지 확인한다.
- 색상 팔레트 선택 후 원의 색상 갱신 및 신규 태그에 해당 색상 저장을 확인한다.
- 유료 버전의 작업 버튼 5개와 체크박스가 좁은 데스크톱 카드 및 모바일에서 한 줄이고 서로 겹치지 않는지 확인한다.
- 폴더 제목 옆 총 용량만 제거하고 문서 개수·개별 문서 용량을 유지한다.
- 폴더 문서 개수 배지를 4px 모서리의 사각형으로 표시한다.
