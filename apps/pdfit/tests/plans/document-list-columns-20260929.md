# 문서 목록 및 표지·LNB 변경 검증 계획

## 환경

Windows 11, 루트 Docker Compose service, Playwright Chromium. 기본 주소는 http://127.0.0.1:15201이며 테스트는 무료 체험 사용자와 PDF·태그 API를 모의한다.

## 절차

1. 공유 패키지와 service를 빌드하고 루트 Compose로 service를 갱신한다.
2. `node apps/pdfit/tests/viewer-tags-free-tier-browser.mjs`를 실행한다.
3. 목록에 이름/열린시간/태그 헤더, 1개 개수 표기가 있고 PDF 아이콘과 수정 문구가 없는지 확인한다.
4. 기록 없는 문서의 열린시간이 —인지 확인하고, PDF를 새 뷰어 창으로 열어 원래 목록에 실제 열기 시각이 반영되는지 확인한다.
5. 목록 태그에 삭제 아이콘이 없고 클릭 시 태그 URL과 LNB 선택이 함께 바뀌는지 확인한다.
6. 폴더·태그 LNB 구역 제목이 아이콘이고 접근 가능한 이름을 유지하는지 확인한다.
7. 표지 체크박스가 카드 안에 있으며 선택·해제가 되는지 확인한다.
8. 390px 폭에서 표지 체크박스와 목록의 가로 잘림을 확인한다.
9. 기존 태그 추가·색상·호버·무료 자동 분류 비활성화와 뷰어 헤더 태그를 회귀 검증한다.

## 통과 기준

모든 UI 변경과 태그 탐색, 실제 열기 시각 갱신이 동작해야 한다. 체크박스가 잘리지 않고 모바일에서 문서 목록이 화면 가로폭을 넘지 않아야 한다. 콘솔 및 페이지 오류가 없어야 한다.
