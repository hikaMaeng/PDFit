# 사이드바 태그 이름 표시 폭

- 생성일은 2026-11-23이다.
- 대상은 Free Docker 서비스 `http://127.0.0.1:15203`과 Chromium 데스크톱(1440×1080), 터치(390×844) 화면이다.
- `설계 및 테스트` 폴더를 펼치고 `마이크로서비스`, `소프트웨어설계`, `테스트주도개발`의 표시 폭, 태그 이름의 시작 위치, 책 수와 첫 도구 버튼 사이 간격을 배포 전후에 측정한다. 폴더 제목은 이름이 일치하는 버튼, 하위 행은 `lnb-folder-tag-row`와 일치하는 텍스트, 첫 도구 버튼은 `lnb-folder-tag-remove`로 찾는다.
- 사이드바 너비가 유지되고 예시 태그 이름 세 개가 한 줄에 온전히 보여야 한다. 책 수와 도구 버튼이 겹치지 않고, 데스크톱 호버와 터치 화면에서 기존 도구 버튼을 쓸 수 있어야 한다.
- `node apps/pdfit/tests/tag-folders-browser.mjs`로 드롭, 폴더 접기, 메뉴, 태그 이동을 확인한다. `node apps/pdfit/tests/tag-editing-browser.mjs`로 편집 버튼을 확인한다.
- Docker 헬스 상태, 컨테이너의 라이브러리 접근, 브라우저 스크린샷, 측정값, 페이지 오류를 기록한다.
