# 문서 목록과 LNB 글꼴 통일 검증

## 목적

문서 목록 파일명을 LNB 태그명의 글꼴 계열, 굵기 및 자간 기준으로 통일해 라이트 모드 선명도 차이를 줄인다. 목록의 기존 글자 크기와 배치는 유지한다.

## 환경

- Windows 11, Docker Compose `service`, Chromium/Playwright
- 로컬 서비스 `http://127.0.0.1:15201`
- 실제 문서 및 폴더 데이터는 읽기만 수행

## 절차

1. `@pdfit/pdfit`, `service`를 빌드하고 루트 Compose에서 서비스를 재생성한다.
2. 기본 폴더와 태그 폴더에서 파일명과 LNB 태그명의 계산된 글꼴·굵기·합성을 비교한다.
3. 라이트/다크 모드 스크린샷을 확인하고 페이지 오류·배치 깨짐을 점검한다.
4. 기존 브라우저 회귀 테스트, `git diff --check`, Compose 상태를 확인한다.

## 통과 기준

- 파일명과 LNB 태그명의 글꼴 계열·굵기·합성이 일치
- 파일명 크기와 행/열 배치가 유지되고 양쪽 색상 모드에 오류가 없음
- 서비스가 healthy 상태
