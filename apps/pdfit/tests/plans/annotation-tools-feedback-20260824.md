# 주석 도구 활성화 및 동작 검증 계획

## 목적

형광펜, 텍스트 추가, 자유 그리기, 사각형, 원, 선, 화살표 버튼을 선택했을 때 활성 상태를 즉시 인지할 수 있고, 각 조작으로 주석이 생성·저장되는지 검증한다.

## 환경

- Windows 11
- 루트 `docker-compose.yml`의 `pdfit` 서비스
- Chromium Playwright, `http://127.0.0.1:15201`
- PDFGPU 기본 경로와 `?engine=legacy` PDF.js 호환 경로

## 절차

1. PDFit 라이브러리에서 PDF 문서를 연다.
2. 7개 주석 도구 버튼을 차례로 클릭한다.
3. 각 버튼의 선택 상태, 도구별 안내 문구, PDF 레이어의 커서를 확인한다.
4. 텍스트는 위치 클릭 후 입력하고, 나머지 도구는 PDF 페이지 내부를 드래그한다.
5. 각 SVG/HTML 주석과 annotation POST 응답을 확인한다.
6. 1페이지 보기에서 다음 페이지로 이동하고 이전 페이지 주석이 렌더링되지 않는지 확인한다.
7. 2페이지 보기에서 다음 펼침면으로 이동하고 이전 펼침면 주석이 렌더링되지 않는지 확인한다.
8. PDFGPU와 PDF.js 호환 경로에서 같은 시나리오를 반복한다.
9. 각 실행에서 만든 검증용 주석 7개를 API로 삭제해 원래 문서 상태를 복원한다.

## 합격 기준

- 7개 도구 버튼 각각 `aria-pressed=true`
- 선택한 도구에 맞는 사용 안내 표시
- 텍스트는 `text`, 나머지 그리기 도구는 `crosshair` 커서
- 조작 후 해당 주석 개수가 1 증가하고 POST가 HTTP 201
- 1페이지 보기의 `1→2` 이동 후 1페이지에서 만든 주석 DOM 0개
- 2페이지 보기의 `1–2→3–4` 이동 후 1–2페이지에서 만든 주석 DOM 0개
- 2페이지 보기의 다음/이전 버튼이 2페이지 단위로 이동
- PDFGPU와 PDF.js 호환 경로 모두 동일하게 통과
- 브라우저 콘솔 및 페이지 오류 없음
