# 태그 폴더 편집 검증 계획

2026-11-24 KST에 작성했다.

- Windows의 격리 Free Compose 프로젝트에 전용 데이터 경로와 `Fixture/fixture.pdf`를 사용한다. 운영 DB에는 테스트 데이터를 쓰지 않는다.
- [API·PostgreSQL 테스트](../../../../packages/pdfit/tests/tag-folders.test.mjs)에서 기존 스키마의 폴더와 태그 소속을 이관한다. 중복·잘못된 요청, 수정 후 동일 ID, 이웃이 바뀐 동시 이동 요청을 검증한다.
- [브라우저 시나리오](../tag-folder-edit-browser.mjs)에서 폴더 3개를 만들고 위로 이동, 중복 이름 거부, 이름·색상 저장, 아래로 이동을 실행한다. 다른 탭과 새로고침 후에도 이름·색상·순서·접힘·태그 소속이 맞아야 한다.
- 모바일 터치 에뮬레이션에서 메뉴를 열어 위로 이동하고 기본 색상으로 되돌린다. 마지막에 테스트 폴더와 태그를 정리한다.
- 폴더 행은 `lnb-tag-folder`, 아이콘은 `lnb-tag-folder-icon`으로 찾는다. 편집·이동은 폴더 이름을 포함한 버튼 이름으로 찾고, 입력은 이름이 있는 편집 대화상자 내부에서 찾는다.
- API 및 DB 결과, Chromium 페이지 오류, 세 화면의 스크린샷과 Free 배포의 컨테이너 및 HTTP 건강 상태를 기록한다.
