# 개인 문서 정보 입력 간소화 검증

## 목적

일반 PDF의 문서 정보 기본 탭에서 작성자·작성 기관·작성일을 숨기고 제목·부제·키워드 중심으로 표시한다. 공개 도서 정보 검색이 성공한 경우에만 도서 전용 항목을 표시한다. 기존 저장 메타데이터 값은 삭제하지 않는다.

## 환경

- Windows 11, Docker Compose `service`, Playwright Chromium
- 로컬 미리보기 `http://127.0.0.1:15201`
- 브라우저 검증 중 데이터 저장 요청 없음

## 절차

1. `@pdfit/pdfit`, `service` 빌드 및 루트 Compose 서비스 갱신
2. 일반 문서 정보 창에 제목·부제·키워드만 있고 작성자·작성 기관·작성일·언어가 없는지 검사
3. 일반 문서에 수동 도서 입력 버튼이 없고, 검색 성공 후에만 저자·역자·출판사·출간일·ISBN이 있는지 검사
4. 화면 캡처, 브라우저 오류, 저장 요청, `git diff --check`, Docker 상태 점검

## 통과 기준

- 일반 문서의 불필요한 필드 4개 숨김
- 도서 정보 필드 유지
- 빌드/브라우저 검사 통과 및 Docker 서비스 healthy
