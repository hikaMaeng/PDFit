# 문서 목록 태그 열 간격 검증

## 환경

- Windows 11, 루트 Compose `service`, Chromium 1280×800
- 로컬 미리보기 계정 사용. 원본 문서 및 태그 데이터는 변경하지 않는다.

## 단계

1. `/folder/PDFit%20Library`와 `/tag/디자인`을 같은 뷰포트에서 연다.
2. 태그 열의 시작 좌표·너비와 칩 끝→태그관리 시작 간격을 측정한다.
3. 폴더 목록의 태그관리 끝→AI 자동 태그 아이콘 시작 간격을 측정한다.
4. 패키지, 서비스 순으로 빌드하고 Compose 갱신 후 같은 측정을 반복한다.

## 기대 결과

- 두 목록의 태그 열 시작 좌표 및 너비가 동일하고 열 너비는 최소 208px이다.
- 칩↔태그관리, 태그관리↔AI 아이콘 간격은 모두 12px이다.
