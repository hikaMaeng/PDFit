# PDF 뷰어 레이아웃·연속 스크롤 검증 계획

## 목적

한 페이지/두 페이지 레이아웃과 연속 스크롤을 독립적으로 선택할 수 있고, 모드 전환·가로 맞춤·북마크 사이드바 표시 후에도 현재 페이지와 화면 폭이 올바르게 유지되는지 브라우저에서 검증한다.

## 환경

- Windows 11
- Docker Compose `service` 컨테이너
- Playwright Chromium, 1440×1000, 한국어 로케일
- 6페이지 테스트 PDF와 API 응답은 브라우저 라우팅으로 고정

## 절차

1. 3페이지, 한 페이지 보기 상태로 뷰어를 연다.
2. 페이지 표시 영역이 툴바 오른쪽 절반에 있는지 확인한다.
3. 두 페이지 보기를 선택하고 두 페이지가 뷰포트 가로폭 안에 함께 표시되는지 확인한다.
4. 연속 스크롤을 켜고 두 페이지 선택이 유지되는지 확인한다.
5. 모드 전환 전의 3페이지가 현재 페이지로 유지되고 3·4페이지가 같은 행에 표시되는지 확인한다.
6. 가로 맞춤 후 북마크 사이드바를 열어 뷰포트가 사이드바 오른쪽에서 시작하고 페이지 폭이 줄어든 뷰포트에 다시 맞춰지는지 확인한다.
7. 브라우저 콘솔 및 페이지 오류가 없는지 확인한다.

## 통과 기준

- 두 페이지+연속 스크롤 버튼이 동시에 선택된다.
- 현재 페이지가 3으로 유지된다.
- 두 페이지가 같은 행에 있으며 뷰포트 폭을 넘지 않는다.
- 페이지 표시가 오른쪽 상단에 있다.
- 사이드바와 뷰포트가 겹치지 않고 가로 맞춤 폭이 재계산된다.
- 콘솔/페이지 오류가 없다.
