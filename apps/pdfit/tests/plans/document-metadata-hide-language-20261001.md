# 문서 정보 언어 입력칸 제거 검증

## 목적

문서 정보 기본 탭에서 사용하지 않는 `언어` 입력칸을 없애고, 일반 문서와 도서 문서의 작성일/출간일 배치를 정리한다. 기존 메타데이터의 `language` 값은 삭제하지 않는다.

## 환경

- Windows 11, Docker Compose `service`, Playwright Chromium
- `http://127.0.0.1:15201` 로컬 미리보기 계정
- 기존 문서·폴더 데이터는 읽기만 수행

## 절차

1. `@pdfit/pdfit` 및 `service` 빌드 후 Compose 서비스를 갱신한다.
2. 일반 문서의 정보 창에서 `언어` 입력칸이 없고 `작성일`이 표시되는지 확인한다.
3. 도서 항목 직접 입력 모드에서 `언어` 입력칸이 없고 `출간일`, `ISBN`이 표시되는지 확인한다.
4. 두 모드를 스크린샷으로 확인하고 페이지 오류, `git diff --check`, Docker 건강 상태를 확인한다.

## 통과 기준

- 두 모드 모두 `언어` 입력칸 없음
- 일반 문서: 작성일 전체 폭. 도서 모드: 출간일과 ISBN 두 칸
- 저장 동작 또는 문서 데이터 변경 없이 브라우저 테스트 성공
