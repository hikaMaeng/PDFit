# 실제 표지 교체 오류·반영 속도 검증 계획 — 2026-11-17

## 요구 기준 (사용자 보고 원문)

> 오류 조사 및 속도개선. 오류도 문제일 뿐더러 썸네일이 반영되는 속도도 느림

함께 받은 증거: 「실제 책 표지로 바꾸기」 대화상자에 "표지를 바꾸지 못했습니다. File not found."

## 가설과 확인

1. **오류 원인:** `PUT /api/covers`가 라이브러리 디스크에 `statSync`로 파일 존재를 확인한다. 컨테이너의 `/app/data/books`가 `Host is down`(SMB 끊김)이면 false가 되어 404가 난다. 끊긴 마운트의 동기 stat은 서버도 멈추게 한다. 확인: 컨테이너에서 `find /app/data/books` 결과, 수정 전후 `PUT` 응답.
2. **속도 원인:** 미리보기에서 받은 이미지를 적용 때 다시 내려받는다. 확인: 단위 테스트에서 같은 URL의 외부 요청 횟수.

## 절차

1. `node --test packages/pdfit/tests/real-covers.test.mjs` (신규: 볼륨 끊김 + 재다운로드 없음).
2. `npm run deploy:standalone` 후 실제 서버(15203)에 `PUT /api/covers`를 보내 응답과 소요 시간을 잰다.
3. 브라우저에서 대화상자로 표지를 적용하고 카드 썸네일이 바뀌는 시간을 잰다.
