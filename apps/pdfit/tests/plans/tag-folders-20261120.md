# 태그 폴더

## 요구 기준 (사용자 요청 원문)

> 1. 태그폴더라는 기능이다.
> 2. 상단에 폴더 추가 아이콘이 들어가고 누르면 이름을 넣어서 새로운 폴더를 만들 수 있다.
> 3. 폴더는 미분류 바로 밑에 폴더만 우선적으로 유니코드순 정렬이 되고 그  다음에 태그가 나온다.
> 4. 폴더는 태그를 넣을 수 있다.
> 5. 일단 폴더로 드래그해서 옮겨진 태그는 하단 태그 리스트에는 안보이고 폴더안에서만 보인다.
> 6. 폴더는 접었다 펼쳤다 할 수 있다.
> 7. 폴더는 삭제할 수 있고 삭제하면 태그는 해당 폴더에서 제거된다.
> 8. 태그는 여러개의 폴더 소속일 수 있다.
> 9. 폴더자체는 접히거나 펼쳐지는 기능만 제공하고 책리스트는 여전히 태그를 눌러서 보는 것이다.

(첨부 스크린샷: 사이드바 "태그" 헤더의 인덱스 아이콘 왼쪽에 빨간 상자 — 폴더 추가 아이콘 위치.)

## 해석

- 폴더는 사이드바 태그 영역의 그룹이며 책 폴더(라이브러리 폴더)와 무관하다. 저장은 서버 DB(`tag_folders`, `tag_folder_tags`).
- 폴더 이름은 공백을 다듬은 1~100자, 같은 이름은 하나만 둔다(요청에 없는 제한이라 최소한으로 둠).
- 폴더 안에서 다른 폴더로 끌면 "이동"이 아니라 "추가"다(8번: 여러 폴더 소속). 폴더에서 태그만 빼는 버튼(요청에 없음)을 두어
  어느 폴더에도 안 속하면 하단 목록에 다시 보이게 한다.
- 접힘 상태는 브라우저 `localStorage`에 기억한다(요청에 없음). 기본은 펼침.
- 범위 밖: 터치 기기의 드래그(HTML5 드래그 사용, 기존 책→태그 드래그와 동일 한계), Pro(호스팅) 저장소 구현(501이면 UI 숨김).

## 절차

1. `npm run deploy:standalone`.
2. `node --test packages/pdfit/tests/tag-folders.test.mjs`(라우트·이벤트·501). 컨테이너 안에서 `PDFIT_TEST_DATABASE_URL`을 줘 PostgreSQL 동작을 격리 스키마에서 검증.
3. `node apps/pdfit/tests/tag-folders-browser.mjs` (임시 폴더 둘을 만들고 끝에서 지움).
4. 회귀: `favorites-browser.mjs`, `untagged-browser.mjs`(사이드바 변경), `npm run verify:repo`.
5. 컨테이너 `healthy`, 최근 로그 error/fatal.

## 합격 기준 (요구 번호별)

- 2: 태그 헤더의 폴더 추가 버튼 → 이름 입력 → 폴더 행 생성, 같은 이름은 대화상자에서 거부.
- 3: DOM 위치가 미분류 < 첫 폴더, 마지막 폴더 < 첫 일반 태그. 폴더 순서는 이름 유니코드 순(생성 순서와 다르게 만들어 확인).
- 4·5: 태그를 폴더로 드래그하면 서버 `GET /api/tag-folders`에 반영되고, 일반 목록의 행은 0개, 폴더 안에 1개.
- 6: 접으면 폴더 안 목록이 사라지고 `aria-expanded=false`, 새로고침 뒤에도 유지, URL은 그대로.
- 7: 삭제 확인 후 폴더가 사라지고 태그는 일반 목록으로 돌아오며 `GET /api/tags/summary`의 태그 이름 목록이 시작 전과 같다.
- 8: 한 태그가 두 폴더 안에 동시에 보인다(행 2개).
- 9: 폴더 클릭은 URL을 바꾸지 않고, 폴더 안 태그 클릭은 `/tag/<이름>`으로 이동한다.
