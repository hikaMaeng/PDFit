# 같은 계정 PC·태블릿 폴더·태그 동기화

## 환경

- 로컬 Docker Compose `service`와 Playwright Chromium 두 개의 독립 브라우저 컨텍스트
- 두 컨텍스트는 동일한 인증 계정으로 `pdfit.io`에 해당하는 단일 서비스 Origin을 사용
- API 응답은 공유 메타데이터 스냅샷으로 대체; PC 1280px, 태블릿 터치 1024px

## 절차

1. 두 기기에서 태그 없는 같은 문서 목록을 연다.
2. 태블릿에서 AI 자동 태그를 적용한다.
3. PC 화면으로 돌아와 포커스 갱신 후 문서 행과 LNB에 태그가 표시되는지 확인한다.
4. 태블릿에서 태그를 초기화하고 PC 포커스 갱신 후 태그가 사라지는지 확인한다.
5. 서버의 폴더 이름 변경을 모사하고 PC 화면 복귀 후 LNB가 새 이름으로 바뀌는지 확인한다.
6. 태블릿 페이지 보기에서 연속 스크롤을 끈 뒤 손가락 쓸기로 페이지 이동을 확인한다.

## 실패 기준

- 로그인 후 또는 화면 복귀 후 이전 IndexedDB 데이터가 서버 변경을 가림
- 태그 추가·초기화 또는 폴더 변경이 다른 기기에 반영되지 않음
- 페이지 모드에서 화살표 없이 손가락 쓸기로 넘길 수 없음
