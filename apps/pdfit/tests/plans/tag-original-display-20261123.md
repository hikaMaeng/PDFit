# 태그 원문 표시 검증

## 환경과 준비

Free Docker의 실제 서재를 로컬 Chromium에서 한국어와 영어로 연다. `/api/tags`, `/api/tag-folders`, `/api/tags/index`, 책별 태그 API를 표시값의 기준으로 사용한다. 기본 검증 태그 `AI App`에는 책과 소속 태그 폴더가 있어야 한다. 다른 태그는 `PDFIT_TEST_TAG`로 지정할 수 있다.

## 절차와 기대 결과

1. 브라우저에서 AI 번역 사용 가능 응답을 설정하고 번역 요청에는 입력과 다른 문자열을 돌려준다. 화면에 보이는 태그는 API 값 그대로이며 번역 요청에는 일반 서재 폴더 이름만 들어간다. 영어 UI의 일반 서재 폴더 제목에는 응답이 반영된다.
2. 사이드바 일반·폴더 소속 태그와 폴더 제목, 폴더 선택 메뉴, 수정 툴팁·입력값, 삭제 확인, 상세 제목, 인덱스의 모든 제목을 확인한다.
3. 태그 상세의 표지·목록, 서재 폴더, 검색, 즐겨찾기, 뷰어에서 태그 칩의 텍스트와 툴팁을 대조한다. 미분류 화면에는 태그 칩이 없다. 책별·일괄 관리창은 현재 태그나 자동완성 선택 항목을 원문으로 표시한다.
4. 태그가 표시되는 DOM의 `translate` 속성, 브라우저 예외, 책별 태그 관계를 확인한다. 즐겨찾기 응답은 기존 책 한 권으로 대체하고 뷰어 진행도·목차 쓰기는 차단한다. 책별·일괄 입력은 선택 없이 확인하고 태그 쓰기 요청은 차단한다.

## 실행과 증거

`PDFIT_TEST_CHANNEL=chrome` 환경 변수로 `node apps/pdfit/tests/tag-original-display-browser.mjs`를 실행한다. 기본 주소는 `http://127.0.0.1:15203`이며 `PDFIT_TEST_ORIGIN`으로 바꿀 수 있다. 기본 증거 디렉터리 `test/20261123/tag-original-display/`에 결과 JSON과 표지 스크린샷을 기록한다. 기록 위치는 `PDFIT_TEST_ARTIFACT_DIR`로 지정할 수 있다.

태그 행과 칩에는 `lnb-tag-row`, `lnb-folder-tag-row`, `pdf-tag-chip`을 사용한다. 인덱스는 `tag-index-card-title` 안의 제목을 읽고, 뷰어는 `viewer-header-tags`로 범위를 한정한다. 관리창과 선택 항목은 대화상자, 콤보박스, 옵션 역할로 찾는다.
