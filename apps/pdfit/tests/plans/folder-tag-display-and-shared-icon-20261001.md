# 폴더 태그 표시·공용 서재 아이콘 브라우저 검증

## 환경

- 로컬 Docker Compose `service`, `http://127.0.0.1:15201`
- Playwright Chromium, 한국어, PC 및 태블릿 크기
- Google API 요청은 문서 1개와 자동 태그 결과를 고정 응답으로 대체

## 절차

1. 폴더 목록을 열고 태그 열이 처음에는 빈 상태인지 확인한다.
2. AI 자동 태그를 실행하고 같은 문서 행의 태그 칩이 표시되는지 확인한다.
3. 표지 보기로 바꿔 태그 칩이 유지되는지 확인한다.
4. 공용 서재에서 문서명 앞 PDF 아이콘이 없는지 확인한다.
5. PC와 태블릿 크기에서 반복한다.

## 실패 기준

- 자동 태그 성공 후 태그 칩이 보이지 않음
- 공용 서재 문서명 앞 PDF 아이콘이 남음
