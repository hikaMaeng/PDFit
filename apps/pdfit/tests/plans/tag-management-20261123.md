# 태그관리 모달 검증

## 환경과 준비

2026-11-23. Free Docker 서재를 로컬 Chromium에서 열고 한국어 UI를 사용한다. 기본 주소는 `http://127.0.0.1:15203`이다. 예시 태그 `AI App`에는 책 두 권 이상이 있어야 한다. 다른 태그는 `PDFIT_TEST_TAG`로 지정할 수 있다.

## 절차와 기대 결과

1. 폴더 목록에서 책별 모달을 열고 공통 접두어가 있는 후보 12개를 필터링한다. 첫 네 옵션이 한 줄에 왼쪽부터 나오고, 다섯 번째 옵션이 다음 줄 첫 칸에 놓인다. 화살표와 Enter로 선택하고 마우스로 다른 항목을 추가한다.
2. 네 태그를 추가하면 최근 세 태그가 최신순으로 표시되고 현재 문서에 적용된 태그가 비활성화된다. 추가 요청이 실패하면 목록이 유지된다. 한글 조합 중 Enter에는 요청이 없고, 조합 완료 후 Enter로 새 태그를 추가할 수 있다.
3. 태그 상세와 검색 화면으로 이동해도 같은 기록을 읽는다. 터치 에뮬레이션 390px에서 표지의 관리창을 열고 4열 배치를 확인한다. 자동완성 목록을 열어 둔 채 최근 태그를 눌러 다른 책에 적용하고 중복 기록이 생기지 않는지 확인한다.
4. 일괄 추가 모달에서 4열 배치와 같은 최근 기록을 확인한다. 자동완성 항목을 고르면 일괄 입력창에 이름이 들어간다.
5. 1024px과 390px에서 모달과 자동완성 목록의 너비를 확인한다. 열린 목록을 유지한 채 데스크톱 폭을 571px로 줄여도 목록이 모달 본문 너비를 따른다. 571px과 390px에서 긴 한국어 이름이 두 줄 이내에 잘리지 않고 표시된다.

## 실행과 증거

`node apps/pdfit/tests/tag-management-browser.mjs`를 실행한다. `PDFIT_TEST_ORIGIN`, `PDFIT_TEST_CHANNEL`, `PDFIT_TEST_ARTIFACT_DIR`로 주소, Chromium 채널, 증거 위치를 바꿀 수 있다. 기본 증거 위치는 `test/20261123/tag-management/`이다. 브라우저 컨텍스트에서 태그 선택지와 변경 응답을 대체하고, 실제 책의 태그가 유지되는지 확인한다. 스크린샷, 요청 순서, 브라우저 오류를 기록한다.

한국어 `태그관리` 대화상자에서 `태그 추가` 콤보박스와 `최근 추가한 태그` 그룹을 찾는다. 자동완성에는 `listbox`와 `option` 역할을, 표지 카드와 현재 태그에는 `pdf-cover-card`와 `pdf-tag-chip`을 사용한다.
