# 라이트 모드 문서 파일명 선명도 검증

## 목적

라이트 모드의 문서 목록 파일명이 300 굵기로 인해 흐릿해 보이는 현상을 완화한다. 다크 모드의 가는 글씨는 유지한다.

## 환경과 범위

- Windows 11, Docker Compose `service`, Chromium/Playwright
- `http://127.0.0.1:15201`의 목록형 문서 보기
- 기본 폴더와 태그 폴더는 공통 `PdfListItem`을 사용한다.
- 문서/폴더 데이터는 변경하지 않는다.

## 절차

1. `@pdfit/pdfit` 및 `service`를 빌드하고 루트 Compose로 서비스 이미지를 갱신한다.
2. 라이트·다크 모드의 기본 폴더와 `소프트웨어` 태그 폴더에서 파일명의 계산된 글꼴, 굵기, 합성 여부를 확인한다.
3. 각 화면을 촬영해 행 배치와 실제 선명도를 비교한다.
4. 기존 폴더 이름 변경 브라우저 회귀 테스트와 `git diff --check`를 실행한다.

## 통과 기준

- 라이트 파일명: 일반 굵기 400, 다크 파일명: 가벼운 굵기 300
- 두 모드 모두 `font-synthesis: none`, 페이지 오류 없음
- 목록 배치 유지, 서비스 healthy
