# Test Report: Acrobat-compatible viewer zoom

## Timestamp

2026-09-28 11:52:00 +09:00

## Environment

- OS: Windows 11
- Browser: Playwright Chromium, headless, 1440 x 1000 viewport
- Runtime: root `docker-compose.yml` `service` container
- Service URL: `http://127.0.0.1:15201`
- Fixture: one-page Letter PDF, 612 x 792 PDF points

## Steps and Results

1. Built `@pdfit/pdfit` with TypeScript: PASS.
2. Ran `packages/pdfit/tests/pdf-display-scale.test.mjs`: PASS, 3 tests, including the no-saved-state 100% default.
3. Built the service Vite and server artifacts: PASS.
4. Rebuilt and recreated the root Compose `service` container: PASS.
5. Verified `GET /health`: PASS, `{ "ok": true, "service": "pdfit-service" }`.
6. Opened the deployed PDF.js viewer with no persisted viewer state: PASS, the initial zoom input was 100%.
7. Measured the page at 100%: PASS, 816 x 1056 CSS pixels.
8. Entered 125% and measured the page: PASS, 1020 x 1320 CSS pixels.
9. Activated fit width: PASS, 1392px page width in a 1440px viewport with 48px viewer padding.
10. Activated fit height: PASS, 865px page height in a 913px viewport with 48px viewer padding.
11. Checked browser console and page errors: PASS, none.

## Observed Logs

- Browser result: `{"status":"PASS","zoom100":{"width":816,"height":1056},"zoom125":{"width":1020,"height":1320},"widthFit":{"width":1392,"height":1801,"viewportWidth":1440,"viewportHeight":913},"heightFit":{"width":668,"height":865,"viewportWidth":1440,"viewportHeight":913}}`
- Vite emitted its existing chunk-size advisory; it did not fail the build.
- Docker Compose reported that the pre-existing `pdfit-service-data` volume was not created by Compose; the service remained healthy and retained the configured data volume.

## Failures

- The first browser-test implementation used Playwright `waitForFunction`, which the deployed CSP correctly rejected because it relies on evaluated JavaScript. The test was changed to poll measurements through DOM locator evaluation and then passed. No application security policy was relaxed.
- The first 125% rendering measured 1019 x 1319 pixels because the previous canvas sizing used floating-point floor. Page, canvas, and placeholder sizing now round to the nearest pixel; the rerun measured the expected 1020 x 1320 pixels.

## Reproducibility

1. `npm run build --workspace=@pdfit/pdfit`
2. `node --test packages/pdfit/tests/pdf-display-scale.test.mjs`
3. `npm run build --workspace=service`
4. `docker compose build service`
5. `docker compose up -d --force-recreate service`
6. `node apps/pdfit/tests/pdf-zoom-acrobat-browser.mjs`
