# Scan status modal verification

## Environment

2026-11-27 KST. Windows, Chrome via Playwright, and an isolated Free Docker instance at `http://127.0.0.1:15447`. The Compose project used a dedicated loopback port, networks, library files, and PostgreSQL data. Follow the [document scan test plan](../../plans/viewer-scan-20261124.md) to recreate the five scan fixtures. The layout scenario used an additional generated 404-page PDF with a browser fixture marking pages 1 through 347 as saved.

## Results

| Scenario | Observed result |
| --- | --- |
| PDF.js at 1280 × 900 | 17 columns with all 404 pages visible, 10 px numbers, 18 px tile height, 3 px gaps, and 8 px of body padding below the final row. X closed the dialog and restored focus to Scan. |
| Touch-enabled PDFGPU at 320 × 730 | 8 columns. The Korean title and both legends fit on one row. The header stayed in place while the grid scrolled to page 404. The first tap on X closed the dialog. |
| Localized header at 320 px | Both legend labels stayed visible in all 12 languages. The computed right padding and distance from the header's right edge to the button were 5 px, including in Arabic RTL. Longer titles used an ellipsis in eight languages. The full title remained the heading and dialog name. |
| Full scan browser scenario | Passed all 10 recorded checkpoints with zero browser page errors. The held-response model handled 13 calls at a peak concurrency of two. The run covered cancellation, failure recovery, and foreground request ordering. |
| OCR tests | 10 passed. |
| Docker | The Free image built, all six fixture PDFs were visible inside the library mount, and the published `/health` returned HTTP 200. Docker reported `healthy` with zero restarts. |

## Locator outcome and artifacts

The exact localized name identifies the dialog and heading. The legend uses visible text, X uses the localized Close button name, and page tiles expose named list items. The 404-page layout run reported zero browser page errors. The touch run left focus outside the Scan trigger after closing. Mouse click and Escape returned focus to the Scan trigger.

The first Compose attempt exhausted Docker's default address pools. Dedicated test subnets resolved the failure. Running the multilingual and full scan scenarios concurrently timed out during the translation-queue check. The full scenario passed when run alone against a fresh fixture database.
