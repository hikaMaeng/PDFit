## Reproducibility

Run the database test against the deployed runtime from the workspace root in
PowerShell.

```powershell
Get-Content -Raw -Encoding UTF8 packages/pdfit/tests/recent-books.test.mjs |
  docker compose --profile standalone exec -T -e PDFIT_TEST_STORE_MODULE=/app/dist/node_modules/@pdfit/pdfit/dist/server/postgres/index.js pdfit node --input-type=module
```

The browser used the **폴더** button and the **신규등록** link and heading
by accessible name. Repeated book links were scoped to `recent-book-list` and
`pdf-filename-line` in list view and to `pdf-cover-card` and
`pdf-cover-title-row` in cover view.

Workspace browser evidence is under
`test/20261127/014648_recent-books-headless-browser-test/`. It contains
`scenario.mjs`, `report.json`, `trace.zip`, the desktop list, cover and mobile
screenshots, and a separate smoke report.
