## 변경 및 검증

1. 폴더·태그 목록의 선택 도구 모음과 열 제목이 main 스크롤 상단에 함께 고정된다.
   scrollTop 650에서 고정 위치를 확인했고 제목은 스크롤되며 LNB 위치는 동일하다.
   body scrollY는 0이다. 모바일 390×844에서도 줄바꿈과 가로 넘침 없이 동작한다.
2. 선택 개수는 칩 없이 `2개 선택됨`, 버튼 레이블은 `폴더 이동`, `삭제`이다.
   2개 전체 선택 이동·삭제 모의 API를 각각 2회 확인했다.
3. AI 자동 태그 옆 폴더 휴지통은 제거되고 선택 삭제는 유지된다.
4. 오른쪽 `문서 정보` 열 제목과 정보 버튼 중앙 정렬을 확인했다.
   폴더·태그에서 정보 버튼으로 기존 정보창의 제목 필드가 정상 표시된다.
5. 폴더·태그 제목 아이콘 간격은 실제 8px로 통일했다.
   태그 개수 배지는 폴더와 같은 primary outlined, 4px 모서리, fontWeight 600이다.
6. 데스크톱 체크박스·파일명 간격은 16px이고 헤더·행 그리드도 같이 축소했다.
7. 태그 해제 확인창은 일반 태그 아이콘이며 한국어 안내에 PDF 문구가 없다.
8. 무료 AI 안내 클릭 후 회색 비활성·AI 요청 없음, 유료 실행 정상,
   검색/태그 색상/호버/설정/표지 체크박스 등 기존 회귀 검증이 통과했다.
