## 재현과 변경

수정 전 브라우저에서 Enter로 새 태그를 추가한 뒤 입력값이 `새태그`로 남는 문제를 재현했다. 닫기 동작은 남은 입력값을 다시 추가해 이미 추가된 태그 안내를 발생시킬 수 있었다.

폴더·태그 페이지 자동완성의 선택값을 null로 제어하고 사용자가 입력하거나 지울 때만 입력 상태를 변경했다. 닫기 자동 저장에서는 이미 현재 문서에 연결된 태그를 제외한다.

목록 체크박스를 호버 표시 대상에서 제외하여 항상 보이게 했다. 공통 태그 칩은 본문이나 × 위에 마우스를 올리면 태그 색상 배경과 강조를 표시한다. frontend-design 스킬의 색상·상호작용 지침을 기존 UI 범위 내에 적용했다.
