# 태그 입력 초기 상태와 hover 검증

- 날짜: 2026-10-06 KST, Windows 11, Docker Compose service.
- 공유 TypeScript·서비스 프런트·서버 빌드 통과, Docker 이미지 갱신 및 healthy.
- tag-input-tablet-browser.mjs: 초기 자동포커스 없음, 회색 테두리·라벨, hover 파란색, 활성 파란 추가 버튼, 빈 클릭 포커스만 이동, Enter·IME·색상 저장 요청 검증.
- Chromium 터치 에뮬레이션 통과. WebKit 결과는 실행 출력 참조.
- 테스트 변경 API는 가로채며 실제 서재를 수정하지 않음. 실제 태블릿 키보드 검증은 아님.
- CSS 라벨 전환 애니메이션 완료를 polling으로 기다리고 CSP 때문에 waitForFunction 대신 evaluate 사용.
