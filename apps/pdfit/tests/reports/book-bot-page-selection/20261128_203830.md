# Book Bot 에이전트 도구 검증

Free Bot의 첫 모델 요청에 현재 책과 원본 목차, 대화 기록, 독자의 질문과 도구 세 개가 들어간다. 서버는 모델의 실제 호출을 받은 뒤 도구 결과를 같은 호출 ID로 돌려준다. 한 질의에서 도구를 최대 여섯 번 실행한다. [검증 계획](../../plans/book-bot-page-selection-20261127.md)

격리 Free의 pgvector와 모의 모델을 이용해 현재 책의 30쪽이 첫 결과로 선택되는 것을 확인했다. 점수가 높은 다른 책의 OCR과 이전 리비전의 12쪽은 빠졌다. PostgreSQL은 공통 태그 두 개를 가진 책을 한 개를 가진 책보다 앞에 놓았다. 동명 제목 조회에는 후보 두 건을 반환했다. 모델이 대상을 확정해 다시 요청하자 그 책의 1쪽만 검색됐다. 브라우저는 다른 책의 1쪽 링크를 렌더링했다.

도구 호출 메시지와 함께 온 중간 텍스트는 채팅에 표시되지 않았다. 결과가 확정된 뒤 최종 답변 하나가 저장됐고 새로고침 뒤에도 다시 열렸다. 목차와 대화만 묻는 질문은 도구 없이 한 번의 모델 요청으로 끝났다. 호출 표기만 보낸 응답은 502로 끝났으며 저장된 턴 수는 그대로였다.

실제 APIBond의 Qwen 모델도 격리 Free에서 `list_related_books`를 호출했다. 서버는 실제 호출 ID로 공통 태그 목록을 돌려줬고 두 번째 모델 요청에서 `Other: AI, agents`가 최종 답변으로 저장됐다. 같은 환경에서 빌드와 헤드리스 Chrome, 릴리스 소스 계약, AI·OCR 회귀 테스트 26개를 확인했다.

증거는 `test/20261128/203830_book-bot-agent/`에 있다. `real-tool-smoke.json`과 `integration.log`는 호출과 결과를 기록한다. `browser/final-answer.png`와 `browser/other-book-citation.png`는 답변과 다른 책 링크를 보여 준다.
