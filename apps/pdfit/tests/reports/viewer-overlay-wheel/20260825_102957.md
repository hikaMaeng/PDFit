## 실행 기록

1. `npm run build:pdfit`
2. `npm run deploy`
3. 배포 서비스에서 Playwright Chromium으로 기본/PDF.js 렌더러를 검증했다.
4. 실제 저장 북마크는 읽기 및 페이지 이동에만 사용했고 삭제·수정하지 않았다.
