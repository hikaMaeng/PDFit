## Failures and resolution

- Docker Desktop could not directly bind the mapped `U:` drive and could not reach NAS SMB from its bridge network.
- Anonymous SMB and `hyej` with an empty password were rejected by the NAS.
- A loopback-only Windows TCP bridge plus the configured NAS credentials allowed a read-only CIFS volume without copying 91.39 GiB into Docker storage.
- The original full-workspace deploy build encountered an unrelated PDFGPU release-contract hash mismatch. The local deploy flow was narrowed to the existing `build:pdfit` task so it builds only the packages owned by this runtime.

## Reproducibility

2. Run `npm run deploy` from the repository root.
3. Require the deploy log to report 717 indexed PDFs.
