# iPad PDF 다운로드 응답 검증 결과

- 시각: 2026-10-01 16:58:43 KST
- 환경: Windows 11, 로컬 Docker Compose `service` healthy, Node Playwright Chromium/WebKit 터치 컨텍스트
- 변경: 다운로드 전용 GET/HEAD 응답을 `application/octet-stream` + `Content-Disposition: attachment` + `X-Content-Type-Options: nosniff`로 분리. 일반 PDF 열람 응답은 `application/pdf` 유지.
- 사전 발견: 이전 테스트는 다운로드 이벤트만 검사했다. 실제 저장 바이트를 추가 검사하자 인증되지 않은 로컬 테스트에서 `{"error":"Authentication required."}` 36바이트를 내려받고도 통과했던 점을 확인했다.
- 테스트 보정: 인증된 문서가 없는 로컬 브라우저 테스트는 독립 파일 제공 서버를 연결하고, 다운로드된 파일의 내용을 원본 PDF와 비교하도록 변경했다. 서버 라우트 응답 헤더는 별도 통합 테스트로 검증했다.
- 결과: 공유 라우트 테스트 4/4 통과, WebKit 터치 다운로드 파일 바이트 일치, Chromium 터치 다운로드 파일 바이트 일치, 일반 뷰어 내보내기 테스트 통과.
- 빌드·Docker: `@pdfit/pdfit`·`service` 빌드 성공, 루트 Compose `service` 재빌드 후 healthy.
