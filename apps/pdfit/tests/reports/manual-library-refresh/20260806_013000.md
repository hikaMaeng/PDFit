# Manual library refresh

## Scope

External folder changes can be missed by filesystem watchers. The new
`POST /api/folders/refresh` path re-registers the root and all child-folder
watchers and emits folder/tag change events. It is intentionally
non-destructive: metadata reconciliation is kept on startup and deletion
events, so a transiently unavailable network file cannot erase tags or reading
state. The LNB and folder header expose a manual refresh button.
