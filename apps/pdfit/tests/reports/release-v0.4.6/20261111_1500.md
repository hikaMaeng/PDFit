## 한계

- 비공개 Pro 앱은 빌드·배포·실행 검증하지 않았다. `verify:repo`의 정적 패리티 검사와 `npm run build`만 통과했고, Pro는 배포 보류 상태다.
- 설치 명령(`npm install ...#v0.4.6`)을 빈 폴더에서 실제로 실행해 보는 검증은 하지 않았다(0.4.5 때는 이 검증이 필요한 결함을 찾았다). 태그가 푸시된 뒤에야 가능하다.
- GitHub Release 문서는 만들지 않았다(요청 범위 밖).
- 이 보고서는 푸시 전에 작성했다. 원격 태그가 가리키는 커밋 대조는 푸시 뒤에 `git ls-remote`로 별도로 했고 결과는 대화로 보고한다.
