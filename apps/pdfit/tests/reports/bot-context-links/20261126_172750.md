# Bot context, progress and page links verification

## Environment

2026-11-26, KST. Windows, Docker Desktop, PostgreSQL and headless Chrome. The disposable viewer at `http://127.0.0.1:15427` used a synthetic six-page PDF, current-version OCR, and a gated SSE provider. The regular Free container was verified at `http://127.0.0.1:15203` and its LAN bind.

## Results

| Check | Observed result |
|---|---|
| Context planning | At 150,000 configured tokens, one final call carried 47,244 bytes of OCR with both boundary markers. Clearing the setting caused three evidence calls followed by the final call. An out-of-range Settings value returned HTTP 400. |
| Stage display | Chrome showed the thinking indicator before answer text and the evidence counter at 0/3 while the first section was held. The session count stayed zero during the first staged reply. |
| Stream compatibility | The progress-aware browser received phase events. A request with only the original SSE accept header still began with an answer delta. The original browser scenario passed disconnect, retry and commit checks against the final build. |
| Flexible page references | Chrome rendered five links from `[PDF p. 2]–[PDF p. 3]`, `p.4,`, `(P. 5)` and a paragraph ending in `p.6`. Each clicked page matched the viewer page number. The same citation worked again after moving away. Out-of-range `p.999`, inline code, a partial word and a decimal stayed plain text, as did the external link label. |
| Restored reply | The PDFGPU renderer displayed the restored citations and navigated to their pages. Its viewport appears in the trace. |
| Build and regressions | Both Free build tasks passed. All 48 AI transport, visual OCR and automatic-tagging regression tests passed. The documentation graph check passed. |
| Production setting | Both LM Studio instances behind the configured gateway alias reported a 212,992-token loaded context. The gateway model list omits a context field. Free stored 150,000 on its active LLM, and that value appeared in the production Settings dialog. |
| Configured LLM probe | One SSE call carried 24,222 bytes with both the first and thirtieth page labels. Thinking appeared at 34.48 s and the final reply at 42.02 s cited page 30. An earlier synthetic prompt also used one call and found the name, but omitted the requested page citation. |
| Production deployment | The final `npm run deploy:standalone` completed in about 35 s. Both published health endpoints returned 200. Docker was `healthy` with zero restarts, the 150,000-token setting survived restart, and the in-container volume and 737-PDF index were verified. |
| Production existing chat | Chrome found nine links in a saved answer. Clicking its first link moved the viewer to PDF page 2 and kept Bot open. The browser smoke blocked writes. |
