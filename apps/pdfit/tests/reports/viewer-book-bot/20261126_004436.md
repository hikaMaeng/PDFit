## Evidence and reproduction

Run the [test plan](../../plans/viewer-book-bot-20261126.md) against an isolated instance. This run's local artifacts are under `test/20261126/003724_book-bot/`: `scenario.mjs`, `live-smoke.mjs`, `conversation.png`, `history.png`, `mobile.png`, `live-panel.png`, `trace.zip`, `docker.log`, and `deploy.log`. Set `PDFIT_BOT_LIVE_MODEL=1` to repeat the isolated single-question probe using the configured model.

The toolbar button and floating dialog were targeted by **Bot**. The question, send, history and new-chat controls were targeted by localized role/name. The drag handle was targeted by its title. The history date was read from the `time` element within the named session button.

The long OCR, multi-turn and clip-vision payload checks used a deterministic upstream. Actual-model long-book synthesis, visual reasoning quality, and the hosted runtime were outside this run.
