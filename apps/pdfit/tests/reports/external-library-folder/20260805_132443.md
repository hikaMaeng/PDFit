## Defect fixed during validation

The dedicated viewer uses `BrowserRouter basename="/viewer"`. The old back
handler used router navigation and turned `/folder/이북` into
`/viewer/folder/이북`, which was interpreted as a malformed viewer document and
produced a PDF worker error. It now performs a full navigation to the service
route, and the final browser check confirmed `/folder/이북`.

## Follow-up required for Docker target registration

Configure Docker Desktop/WSL2 to access the SMB share, or provide a
Docker-visible local path. Do not expose SMB credentials in the repository.
