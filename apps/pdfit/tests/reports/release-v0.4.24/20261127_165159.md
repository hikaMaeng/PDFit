## Chrome 플래그 비교

그래픽 가속은 켜져 있었다. 저장된 실험 플래그 12개와 실행 인수를 확인했다. `Use WebGPU adapter`는 `OpenGL ES`, `Choose ANGLE graphics backend`는 `D3D11`이었다. Chrome 158.0.8127.89의 [플래그 정의](https://chromium.googlesource.com/chromium/src/+/refs/tags/158.0.8127.89/chrome/browser/about_flags.cc)에서 두 설정의 실행 인수를 확인했다.

| 같은 PC에서 새 Chrome으로 실행한 진단 | 결과 |
| --- | --- |
| 기본값 | NVIDIA 어댑터로 장치 생성 및 캔버스 초기화 성공 |
| ANGLE D3D11 | 성공 |
| WebGPU 어댑터를 OpenGL ES로 강제 | 어댑터 없음 |
| 두 플래그를 모두 적용 | 어댑터 없음 |

`Use WebGPU adapter`를 기본값으로 돌리고 Chrome을 재시작한 뒤 운영 HTTPS에서 PDF가 열리는지 확인해야 한다.
