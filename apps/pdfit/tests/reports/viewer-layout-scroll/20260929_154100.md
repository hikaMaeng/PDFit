## 참고

PDFGPU 강제 브라우저 실행은 기존 서비스 CSP가 PDFium WASM 초기화에 필요한 실행 방식을 차단하여 기본 뷰어로 자동 전환됐다. PDFGPU React 경계 변경은 TypeScript 빌드와 `pdfgpu-integration` 테스트로 검증했으며, 실제 서비스 브라우저 동작은 자동 전환된 기본 뷰어에서 검증했다.
