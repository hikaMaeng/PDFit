## 변경 검증

1. 왼쪽 주석 도구 막대에 64px 전용 레일을 할당했다.
2. PDF 뷰포트는 레일 오른쪽에서 시작하며 레일 폭을 가로 맞춤 계산에 포함하지 않는다.

4. PDFGPU에서는 PDF 뷰포트·주석 레이어·북마크 캡처 레이어를 같은 내부 좌표계로 묶었다.
