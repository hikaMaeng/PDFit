# 두 페이지 세로 맞춤·라이트 모드 검증

- 시각: 2026-10-01 14:36 KST
- 환경: Windows 11, Docker Compose `service` healthy, Chromium 및 WebKit Playwright

## 절차와 결과

1. PDF.js와 PDFGPU에서 두 페이지 보기의 150% 수동 확대 후 가로·세로 맞춤을 비교했다.
2. 세로 맞춤은 각 페이지 높이를 뷰포트 높이 이하로, 펼친 전체 너비를 뷰포트 너비 이하로 제한했다. 마지막 Docker 빌드에서 PDF.js 세로 맞춤 63%, 페이지 높이 665/713px, 전체 스크롤 너비 1216/1216px. PDFGPU 68%, 페이지 높이 713/713px, 전체 스크롤 너비 1216/1216px.
3. 짧은 PDF에서도 가로 넘침이 없는지 확인했다. PDF.js와 PDFGPU 모두 통과.
4. 라이트 모드에서 PDF 주변 캔버스와 상단 도구막대의 밝은 배경 및 다른 탭의 모드 변경을 확인했다. Chromium PDF.js, WebKit PDF.js, Chromium PDFGPU 테스트 통과.
5. `node apps/pdfit/tests/pdf-zoom-acrobat-browser.mjs`의 기존 단일 페이지 확대·맞춤 회귀 테스트 통과.

## 참고

- PDFGPU 경로는 테스트에서만 CSP의 WASM 허용 헤더를 사용했다. 운영 CSP는 변경하지 않았다.
- PDF 페이지 원본의 색상은 테마 전환 시 변경하지 않는다.
- 운영 사이트 배포 및 실기기 태블릿 검증은 수행하지 않았다.
