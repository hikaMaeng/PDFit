## 정리

배경색과 목차 검증용 Docker 컨테이너 두 개를 제거했다. GitHub `main`에 포함된 PDFGPU 임시 브랜치 `codex/viewer-deskew-toggle`와 worktree 등록을 삭제했다. Windows에서 worktree 폴더가 일부 남았고 자동 승인 검사가 폴더의 재귀 삭제를 차단했다. 미커밋 파일이 있거나 원격 `main`에 없는 작업 브랜치는 보존했다.
