## 재현과 증거

[테스트 계획](../../plans/page-ocr-popup-20261127.md)과
[브라우저 시나리오](../../page-ocr-popup-browser.mjs)를 사용했다.
페이지 제목으로 이름이 지정된 dialog, 한국어 버튼 이름, 공용 리사이즈
핸들, `page-ocr-scroll` 앵커로 조작 및 검증했다.

격리 프로젝트는 별도 책·데이터 디렉터리와 루프백 포트를 사용했다.
Docker 기본 주소 풀이 소진돼 첫 Compose 실행은 네트워크 생성에서
중단됐다. 전용 서브넷 두 개를 지정한 뒤 배포를 완료했다. 패키지
문서 구조 검사는 통과했다. JSON 디렉터리를 가정하는 i18n 검사기는
현재 TypeScript 카탈로그를 찾지 못했다. 카탈로그의 OCR 신규 키
4개에서 각 12개 언어 값이 존재하는 것을 확인했다.
