## 원인

1. 로컬 런타임에서도 폴더 생성 API를 백그라운드로 실행해 서버 성공 전에 폴더 URL로 이동했다.
2. 배포된 CIFS 서재 볼륨이 읽기 전용으로 생성되어 실제 `mkdir` 요청은 `ENOENT`로 실패했다.
3. 두 조건이 결합되어 본문에는 URL 기반 폴더명이 보이지만 LNB/API 목록에는 폴더가 없는 상태가 발생했다.

## 변경

- 메타데이터 캐시가 없는 로컬 런타임은 폴더 생성 서버 응답을 기다린다.
- CIFS 서재 볼륨의 신규 프로비저닝 옵션을 읽기/쓰기로 변경했다.
- 기존 읽기 전용 볼륨을 삭제하지 않고 별도 읽기/쓰기 볼륨으로 로컬 배포 설정을 전환했다.
