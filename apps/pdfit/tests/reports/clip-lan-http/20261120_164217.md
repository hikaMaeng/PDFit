# Clip capture over LAN HTTP

## Timestamp and environment

2026-11-20 16:35–16:42 KST. The test ran in installed Google Chrome `157.0.8103.79` with a visible window, a fresh profile, and a Korean locale. It opened the default PDF.js viewer on `http://192.168.0.6:15203` with `이북/Git for Teams.pdf`, page 3. Chrome reported `isSecureContext: false`, `typeof crypto.randomUUID: 'undefined'`, and `typeof crypto.getRandomValues: 'function'` both times.
