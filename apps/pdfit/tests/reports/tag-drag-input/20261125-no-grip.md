# 사이드바 태그 드래그 검증 · 2026-11-25

[검증 계획](../../plans/tag-drag-input-20261124.md). 격리 Free 0.4.15를 `http://127.0.0.1:15356`에 배포해 Windows 헤드리스 Chromium에서 실행했다. 태그 이동과 책 태그 추가 응답은 브라우저 픽스처에서 제공했다.

| 확인 항목 | 결과 |
| --- | --- |
| 수정 전 운영 0.4.14 | 읽기 전용 브라우저 스모크에서 사이드바 태그 손잡이 105개를 확인했다. |
| 사이드바 태그 5개 시나리오 | 점 6개 손잡이 0개. 태그 이름을 끌어 폴더 빈 영역, 대상 태그, 접힌 폴더 제목에 놓는 동작, 드롭 중 갱신, 390px 화면의 길게 누르기와 드래그가 모두 통과했다. PUT 200, 원본·대상 소속, 재접속 후 상태를 확인했다. |
| 책 카드 7개 시나리오 | 목록 제목, 표지, 고정 표지, 카드 제목, 검색 카드, 좁은 마우스, 휴대폰 터치에서 기존 책 태그 추가가 통과했다. |
| 뷰어 코멘트 회귀 | PDF.js와 PDFGPU, 마우스·키보드·터치 이동, 글 공유가 통과했다. 화면 크기를 바꾼 뒤 ResizeObserver가 새 위치를 반영할 때까지 테스트가 기다리도록 했다. |
| 빌드 | `npm run verify:repo`와 `npm run deploy:standalone` 통과. |

스크린샷과 브라우저 추적은 테스트 호스트의 `test/20261125/tag-handle-0415/browser/`에 저장했다.
