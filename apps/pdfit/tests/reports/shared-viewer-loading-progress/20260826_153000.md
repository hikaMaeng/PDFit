# 공통 PDF 로딩 진행 막대 테스트 보고서

## 결과

- PDFGPU 통합 테스트: 4/4 통과
- 로컬 프로덕션 빌드 및 Docker 재배포: 통과
- 서비스 프로덕션 빌드 및 Docker 재배포: 통과
- Windows 기본 뷰어: 공통 가로 막대 표시, 브라우저 오류 0
- macOS 기본 뷰어: 공통 가로 막대 표시, 브라우저 오류 0
- ASUS GX10 기본 뷰어: 공통 가로 막대 표시, 브라우저 오류 0
- PDF.js 실제 진행률 표본: `1%, 2%, 3%, 5%, 6%, 8%, 9%`, 이후 완료되어 숨김

## 구현 확인

GPU와 기본 뷰어가 `PdfLoadingProgress` 공통 컴포넌트를 사용한다. 기본 뷰어는 PDF.js `onProgress`의 다운로드 바이트와 전체 바이트를 사용해 퍼센트를 계산하고, 전체 크기를 알 수 없는 동안에는 동일한 모양의 무한 진행 막대를 표시한다.
