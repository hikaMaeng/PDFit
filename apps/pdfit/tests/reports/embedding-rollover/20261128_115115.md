`npm run build:pdfit`과 PostgreSQL 통합·회귀 테스트 28건이 통과했다. DB는 Docker의 PostgreSQL 17과 pgvector 0.8.6을 사용했다.

- 첫 HTTP 요청을 보류하고 그 사이에 스케줄러 계획을 세 번 실행했다. 세 주기가 모두 신규 등록을 건너뛰었다. 원문 두 번 수정과 새 문서 삽입을 겹친 뒤 요청을 풀었다. 대기열이 비었을 때 신규 문서는 변경 기록에만 남았다. 다음 주기에서 등록하고 검색했다. 테스트 중 최대 동시 HTTP 요청은 한 건이었다.
