## 실패·수정·제약

- 초기 PointerEvent 방식은 브라우저의 기본 터치 처리 중 `pointercancel`을 받아 넘김에 실패했다. `touchend` 기반으로 조정한 뒤 두 뷰어에서 통과했다.
- PDFGPU의 페이지 모드 DOM은 모든 페이지 높이를 유지하므로 전체 `scrollHeight`로 현재 페이지의 끝을 판단할 수 없었다. 화면 맞춤 상태에서는 스와이프를 페이지 이동으로 처리했다.
- Chromium의 저장 선택기와 데스크톱 WebKit의 `maxTouchPoints=0`을 테스트에서 각각 iPad 조건으로 재현했다. 실제 iPad Safari의 저장 패널은 자동화하지 못했다.
- 공개 `pdfit.io` 배포, 실기기 업로드 체감 속도 및 실기기 터치 동작은 미검증이다.
