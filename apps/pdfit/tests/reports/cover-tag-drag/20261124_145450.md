## 재현 및 증거

- `PDFIT_TEST_ORIGIN`, `PDFIT_TEST_ARTIFACT_DIR`을 지정하고 `node apps/pdfit/tests/cover-tag-drag-browser.mjs`와 `node apps/pdfit/tests/tag-folder-drag-browser.mjs`를 실행한다. 태그 칩은 `pdf-cover-tags` 또는 `pdf-tag-values` 안에서 `title`로 찾았다. 폴더 안 태그는 `lnb-folder-tag-row`의 정확한 이름, 폴더는 `lnb-tag-folder` 안의 이름이 있는 버튼으로 찾았다.
- 기본 폴더 통합 테스트의 운영 사전 조건인 미소속 한국어 태그 3개를 충족하지 않아, 브라우저 픽스처와 격리 DB로 폴더 드롭을 확인했다. 격리 Docker의 첫 기동은 Docker 주소 풀 고갈로 실패했고, 격리 프로젝트 네트워크에 사용 가능한 서브넷을 지정해 재실행했다.
- 기본 워크스페이스의 `test/20261124/tag-drag/`에 `production` 드래그 화면, `production-root-tags` 일반 태그 드래그 화면, `production-smoke` 브라우저 보고서와 추적 파일, `database` 격리 DB 테스트 화면을 저장했다. 실제 저장 검사는 Free Chrome과 격리 PostgreSQL 범위다.
