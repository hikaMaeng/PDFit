2. Reused YES24 catalog lookup for missing or placeholder outlines, using title identity for MCP and ISBN for SLM. The first direct PDF.js run found SLM's front matter on a printed contents page and assigned the absent MCP index a late body page. Excluding early pages with repeated contents headings corrected the SLM match. Limiting extrapolation to observed print numbering removed the MCP index link.
3. The independent code review found ambiguous pre-upgrade manual edits, disabled-only outlines being cacheable, repeated printed page numbers, and mixed chapter labels. The candidate preserves existing data with unknown provenance, avoids caching disabled-only outlines, keeps duplicate print-page candidates until a heading disambiguates them, and retains bare chapter labels. Multiple ISBN candidates receive bounded checks. Concurrent explicit writes still use the last completed write; conditional first-open initialization protects stored edits and deletions.
