# Viewer floating panels verification

2026-11-25 14:19 KST. Windows, local Free Docker, `http://127.0.0.1:15203`.
Chrome 158.0.8127.89, Korean UI, 1280 × 900 desktop and 393 × 740 with emulated
touch. Playwright supplied the synthetic PDF and clip API responses in memory.

| Check | Observed result |
| --- | --- |
| `npm run deploy:standalone` | Both builds passed in 41.849 seconds. Docker recreated Free and reported `healthy`. `/health` returned HTTP 200. The container could see 733 PDFs under `BOOKS_ROOT`, and refresh indexed 733 PDFs across two folders. |
| PDF.js and PDFGPU geometry | The PDF viewport matched the main region's width in one-page, two-page, and continuous modes. At width fit it remained 1280 px. The page remained 1256 px wide in PDF.js and 1272 px in PDFGPU throughout panel operations. |

| Narrow viewport | Both panels stayed within the viewport. An emulated touch drag moved the clip list. After reload both positions were retained, and Clips started closed. |
| Regression checks | All five PDF.js fit scenarios and 15 annotation and spread tests passed. The clip-list action produced one unchanged geometry sample in the fit check. The docs graph passed, and all three new labels have values in 12 languages. |

zero console and uncaught page errors for both engines. The evidence directory
contains `result.json`, screenshots, traces, and `fit-stability/result.json`.
