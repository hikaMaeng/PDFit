# PDFGPU scroll-boundary stability

## Result

Passed on the deployed `pdfit` container with the real library PDF `1. 이벤트소싱과 마이크로서비스 아키텍처 472p.pdf`.

The browser test opened the document with WebGPU enabled and sampled scroll positions at `0`, `1,200`, `2,400`, `4,800`, `9,600`, `16,000`, and `24,000` pixels.

| Check | Result |
| --- | --- |
| Backend | `webgpu` |
| Pages | `23 / 472` at final sample |
| Scroll height | `512,054px` |
| Overlay canvas top | `110px` at every sample |
| Idle `scrollTop` range | `24,000..24,000` |
| Browser errors | `0` |
| Docker health | `healthy` |
