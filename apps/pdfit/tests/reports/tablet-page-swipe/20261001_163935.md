# 태블릿 페이지 보기 제스처 회귀 결과

- 시각: 2026-10-01 16:39:35 KST
- 환경: Windows 11, Docker Compose `service` healthy, Playwright Chromium 터치 컨텍스트 768×1024 및 1024×1366, PDF.js 및 WebGPU 모드
- 절차: 연속 스크롤을 끈 상태에서 세로 쓸기와 좌우 쓸기로 다음·이전 페이지/묶음을 이동. 화면 맞춤의 `touch-action`과 연속 스크롤의 기본 터치 스크롤을 확인. 300% 확대 후 가로 스크롤 중간에서 쓸어 페이지가 넘어가지 않는지 확인.
- 사전 재현: `--horizontal-swipe`는 두 뷰어 모두 페이지 1에서 멈춰 10초 후 실패. 기존 세로 맞춤 테스트만 통과하여 좌우 제스처 누락을 발견.
- 결과: 수정 후 레거시·GPU 모두 좌우 다음/이전 묶음, 세로 다음/이전 페이지 통과. 300% 확대 시 문서 내부 이동 우선, 연속 스크롤 모드 기본 터치 허용 통과.
- 로그: `--horizontal-swipe`·`--horizontal-swipe --gpu`·`--touch-swipe`·`--touch-swipe --gpu` 모두 성공. 1024×1366의 좌우 테스트와 일반 배율 세로 테스트도 성공. `node apps/pdfit/tests/viewer-toolbar-export-browser.mjs` 성공.
- 빌드·배포: `npm run build --workspace @pdfit/pdfit`, `npm run build --workspace service`, `docker compose up -d --build --wait --wait-timeout 60 service` 성공.
- 검사: `git diff --check` 성공.
- 재현: `node apps/pdfit/tests/viewer-double-fit-height-browser.mjs --horizontal-swipe`; 같은 명령에 `--gpu`; `--touch-swipe` 및 `--touch-swipe --gpu`; 필요하면 `--large-tablet` 추가.
