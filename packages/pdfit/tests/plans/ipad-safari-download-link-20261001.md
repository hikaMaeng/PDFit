# iPad Safari 문서 다운로드 링크 회귀 계획

## 환경

- Windows 11 TypeScript 빌드 및 로컬 Docker 브라우저 테스트

## 절차

1. 저장 선택 API가 없는 브라우저에는 직접 클릭 가능한 첨부파일 링크를 표시한다.
2. 해당 링크에 `download=1`과 원래 PDF 파일명이 포함되는지 검사한다.
3. 클릭 후 대화상자가 즉시 사라지지 않고 다운로드 이벤트가 발생하는지 검사한다.
4. 저장 선택 API가 있는 PC에서는 기존 파일 선택·쓰기 흐름을 검사한다.
5. 원격 PDF 라우터의 첨부파일 헤더와 일반 인라인 뷰어 헤더를 검사한다.

## 실패 기준

- 프로그램으로 생성한 숨겨진 링크를 클릭함
- 파일명 또는 `attachment`가 누락됨
- PC 저장 기능이 회귀함
