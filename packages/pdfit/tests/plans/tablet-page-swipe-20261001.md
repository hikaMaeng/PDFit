# 태블릿 PDF 페이지 제스처 검증 계획

## 환경

- Windows 11, 로컬 Docker Compose, Playwright Chromium 터치 에뮬레이션

## 절차

1. 레거시·GPU 뷰어의 한 페이지 및 두 페이지 모드에서 연속 스크롤 없이 터치 넘김을 검사한다.
2. 세로 및 가로 방향 모두 다음·이전 페이지로 이동하는지 검사한다.
3. 화면 맞춤의 브라우저 기본 터치 스크롤 차단과 연속 스크롤의 기본 터치 허용을 확인한다.
4. 확대·가로 스크롤 상태에서 한 번의 쓸기가 페이지를 건너뛰지 않는지 검사한다.

## 실패 기준

- 오른쪽 상단 화살표만 페이지를 넘김
- 확대된 문서에서 제스처가 곧장 페이지를 넘김
- 연속 스크롤이 동작하지 않음
