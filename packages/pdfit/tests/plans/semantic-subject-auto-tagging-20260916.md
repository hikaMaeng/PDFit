# 제목 의미 기반 자동 태그 검증 계획

## 목적

서점에서 정확히 일치하는 도서를 찾지 못하고 제목 규칙에도 없는 PDF가, 제목의 핵심 주제를 확인해 기존 태그 체계로 분류되는지 확인한다. 관련 없는 검색 결과를 태그 근거로 사용하지 않아야 한다.

## 환경 및 절차

1. `npm run test:ai-tags`로 제목 분류와 일괄 태그 API 회귀 테스트를 실행한다.
2. `npm run deploy:service`로 서비스를 빌드하고 루트 Compose 컨테이너를 갱신한다.
3. 실행 중인 컨테이너에서 `코어 코틀린`의 분류 결과가 `프로그래밍`인지 확인한다.
4. 사용자 계정, 대상 파일명·크기·폴더가 각각 하나로 확인된 경우에만 태그를 적용한다. 적용 후 메타데이터를 다시 읽어 검증한다.
5. `apps/service`의 `appearance-samples-browser.test.mjs`로 브라우저 일괄 태그 UI를 확인한다.
6. `docker compose ps` 및 서비스 로그로 상태를 확인한다.

## 실패 기록

명령, 종료 코드, 대상 식별 정보, 오류 메시지 및 재현 조건을 보고서에 기록한다. 계정 비밀 값은 기록하지 않는다.
