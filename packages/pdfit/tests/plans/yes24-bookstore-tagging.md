# YES24 서점형 자동 태그 테스트 계획

## 목표

제목 단어가 일회성 태그로 생성되지 않고, 공식 YES24 검색 메타데이터를 근거로 재사용 가능한 도서 분류 태그가 생성되는지 검증한다.

## 범위

- 제목 정규화와 검색 결과 일치도
- 관련 없는 검색 결과 거부
- YES24 부제·소개·요약·목차의 분류 입력 전달
- IT 외 문학·역사·여행·육아·외국어 등 공통 분류
- 로컬/서비스 Docker의 동일 환경 변수 계약
- 15201 서비스 화면의 HTTP 200 및 브라우저 콘솔 오류 부재

## 재현 절차

1. `npm run test:ai-tags`
2. `npm run build:service`
3. `docker compose up -d --build service`
4. Python Playwright로 `http://127.0.0.1:15201/` 접속

## 합격 기준

- 모든 자동 태그 통합 테스트 통과
- 서비스 빌드 성공
- Docker 컨테이너 healthy
- 브라우저 응답 200 및 콘솔 오류 0건
